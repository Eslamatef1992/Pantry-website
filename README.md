# Pantry Website (makanifoods.com storefront)

React (Vite) customer-facing storefront for the Makani Foods / Pantry e-commerce platform.
Bilingual Arabic/English with RTL support (react-i18next).

Sibling repos:
- API: https://github.com/Eslamatef1992/pantry-api
- Admin panel: https://github.com/Eslamatef1992/Pantry-admin

## Setup

```bash
cp .env.example .env   # set VITE_API_URL to the running API
npm install
npm run dev              # http://localhost:5173
```

Requires the `pantry-api` backend running (see its README for setup + seeding).
